MECHANISM
  - Local properties (degree_of_node_0, edge_count) are one tool call away:
    ReAct issues Degree[0] / EdgeCount[] and finishes in ~2 steps, removing
    the zero-shot miscount.
  - Global properties need an aggregate over the whole structure. The model
    spends its step budget on one-at-a-time HasEdge / Neighbors probes and
    often never reaches Finish (see finish rates above); zero-shot at least
    guesses from the full edge list in context. This is the paper's own
    trade-off (Table 2: the structural constraint raises reasoning-error rate).
  - The action parser accepts decorated but valid actions (`Action 3: [Finish[4]]`,
    `**Action 3:** ...`, backticks). The pre-PR#9 run's strict parser rejected
    them, which caused a spurious Gemini edge_count drop; this run used the
    fixed parser from the start (records carry action_parser=2).
